## Who I Am 

I'm a self-taught developer with a Cyber Security background, learning to become an AI Engineer. I'm currently focused on:

- **RAG systems**: retrieval pipelines, chunking, embeddings, vector DBs
- **LLM apps & agents**: LangChain, tool calling, API integrations, automation
- **Data skills**: Python, SQL (window functions, CTEs), Pandas-based EDA, applied math for ML

I believe in learning by building. Every project below was built hands-on, bugs and all.

## Currently Learning

- Deepening my understanding of the RAG pipeline (retrieval → chunking → embeddings → generation)
- Data analysis workflow: cleaning, EDA and preprocessing with Pandas, Matplotlib, Seaborn and Scikit-learn
- Data engineering basics: SQL, star schema, medallion (Bronze/Silver/Gold) pattern, DuckDB, dbt
- FastAPI + Pydantic for production-style APIs (structured LLM outputs)
- LLM evaluation: regression testing for LLM features with golden datasets
- Working toward free certifications: Kaggle Learn, LangChain Academy, Anthropic Academy
